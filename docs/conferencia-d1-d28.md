## Pontos destacados

- D8: não confundir "atrasado" com "antes de hoje". Limites de hoje/sete dias são locais, atraso é comparação com o instante atual; exatamente agora ainda é Hoje.
- D20: autorização continua por integração; o segredo adicional não serve para escolher workspace. Nenhum token real deve ir para exemplos, logs ou Git.
- D22: permissões não eram a trigger solicitada; a defesa agora existe nas duas camadas, em migration nova.
- D26: persistir jobs no broker não bastava para cancelar vencidos ou reconstruir o domínio. Boot executa recuperação explicitamente, preservando a exceção de confirmação imediata de compromisso futuro.
